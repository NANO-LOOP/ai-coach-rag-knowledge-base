# 知识库总入口

这里是 GitHub Markdown 的当前维护知识，支撑“输入 → 判断候选 → 有效提问 → 更新判断 → 条件化建议 → 复评”。所有专业内容仍待专家审阅。

## 按问题阅读

- [18个专业专题](topics/README.md)：运动专项、营养、恢复与通用基础。
- [HYROX 完整问题包](topics/hyrox-prior-load/README.md)：先看一个完整流程。
- [构造对话与反例](cases/hyrox-prior-load-illustration.md)：检查不同回答是否改变下一步。
- [覆盖与待补项](coverage.md)：从哪个专题继续完善。

## 按知识职责阅读

| 类型 | 入口 | 用途 |
| --- | --- | --- |
| 概念 | [concepts](concepts/) | 理解输入、机制和解释边界 |
| 判断 | [assessments](assessments/) | 区分候选解释、支持与反证 |
| 提问 | [questions](questions/) | 只问会改变判断或行动的问题 |
| 证据 | [evidence](evidence/) | 保存有明确来源与迁移限制的结论 |
| 行动 | [actions](actions/) | 保存适用条件、下一步与复评 |
| 案例 | [cases](cases/) | 保存来源明确的过程示例与反例 |
