# 询问并接收专家意见

先明确本轮是在请专家点评，停止运动者角色。读取相关 Markdown 与实际模拟记录，引用具体段落或轮次，不预设专家必须赞同已有正文。

通常先一句说明意见可能怎样改变判断，再问一个能够增加知识的问题。优先追问“什么回答会让你改变判断或建议”；之后按需要补充机制、适用人群、时机、反例与复评，不一次抛出字段问卷。短句和口述由 Agent 整理。

区分专家在更正案例事实、提出专业机制、分享经验、调整目录还是表达偏好。保留“可能”等不确定性；没有否认不等于确认。已有回答不重复询问，专家改题则跟随，并记录未完问题。

数值意见须保留单位、人群、条件和来源；不能因为专家说“还要更多数据”就自行编造生理数据。研究依据与专家经验分别标注；未核验的研究主张记录待核验，不编文献。需要外部科学查证时另行记录原始研究来源，知识维护目标仍是本地 Markdown。

把讨论保存到 `review-data/<session-id>/expert-feedback.md`：对应轮次、专家原话、解释后的修改建议、受影响的 ID/版本/段落、条件与反例、来源性质、尚未解决问题。真实身份未经授权不进入公开库。

信息足够时展示 1–3 项关键修改并交 [知识编辑](../nuromova-knowledge-editor/SKILL.md) 整理草稿，不要求先填完全部字段。不把“可以整理”记录成专业确认；只有专家确实审阅了明确版本及范围才能记录 confirmed。无需要求项目负责人替专家逐条审核。
