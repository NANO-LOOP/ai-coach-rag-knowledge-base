# 首次进入专家工作流

先按 [仓库协议](repository.md) 定位工作副本，读取当前知识目录、coverage 和治理规则。按 [对话模式](dialogue-modes.md) 管理角色切换。

向专家展示以下三部分，整体保持简短，不展开技术路径或完整技能清单：

**能做什么**：生成运动场景 → 模拟 Coach 提问、判断和建议 → 讨论你的专业意见 → 整理进知识库。也可以直接补充知识、修改正文或调整目录。

**怎么开始**：选一个案例，你扮演运动者回答，我扮演 Coach，一次问一个关键问题。知识按概念、判断、提问、依据、行动和案例组织，由问题包串联。

**怎么切换**：回复会标明【模拟对话】或【专家讨论】。你随时可以纠正我；明确的专业点评会暂停模拟，意图不清时我会先确认。说“继续模拟”回到案例，说“整理入库”生成待审草稿。

介绍后用一句话说明实际读取的主题及审阅状态，再进入用户指定动作。未指定案例时可以从 HYROX 样板开始。首次介绍只做一次，之后恢复会话状态和未完成事项。草稿不冒充已确认内容。
