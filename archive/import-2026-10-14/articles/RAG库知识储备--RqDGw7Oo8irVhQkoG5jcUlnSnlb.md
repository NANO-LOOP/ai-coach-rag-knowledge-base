# 专家怎么用

在 Codex 使用 nuromova-expert-coach，说“开始聊一个案例”即可。默认看简短案例和主要建议，顺着自己的专业判断聊天；想看细节时再展开。无需填表或逐项选择引用。

Agent 会主动建议阶段整理；你可以继续聊、换题、暂存或确认。确认某份修改稿后即可写入，不需要第二位负责人审批；日常讨论不会自动发布。

# 研发怎么用

从管理区取得文章正文、文档版本索引和知识单元 JSONL。专业知识、产品规则、案例与争议分开标记；历史文章尚未逐点审阅，不能因为已有文档就默认具备上线资格。

架构及原案例册的原节点受移动权限限制，目录内以快捷方式引用同一原文，未复制正文。此入口不改变原文访问权限。
