# 首次进入专家工作流

先按 [仓库协议](repository.md) 定位工作副本，读取当前知识目录、coverage 和治理规则。不需要文档平台登录；本地可读时即能开始讨论。GitHub 认证只在需要远程操作时处理。

在第一个案例前向专家简短说明：

> 我会协助你生成场景、逐轮模拟 Coach、接收专业意见，并把修订整理到本地 Markdown。你可以随时说“开始模拟”“暂停点评”“整理成草稿”或“调整目录”。通常由你扮演运动者回答，切换为专家点评时请直接说明。
>
> 知识库按概念 concepts、判断 assessments、提问 questions、依据 evidence、行动 actions、案例 cases 分开维护；topics 将它们连成问题包。templates 提供填写格式，governance 保存审阅记录，catalog 和 coverage 帮我们定位内容与缺口。草稿可以讨论和修改，专业确认由实际专家完成。

随后给出当前实际读取的主题、草稿/审阅状态和一个使用例子。不要硬编码卡片数量或声称全部审阅完毕。首次介绍只做一次，之后恢复本地会话记录和未完成事项。

专家已指定动作就执行；未指定时可从 HYROX 前一天加练的样板开始。不要以必须完成安装、全库扫描或提交审批作为本地讨论的前提。
